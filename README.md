Write a short, funny rant about an everyday annoyance and let a furious judge decide which one lands hardest. One short rant about the office printer that has one job and refuses to do it — capped at 400 characters, so the punch comes fast.

## Run it

```sh
node main.ts
```

This writes the rant to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and validates the 1–400 character gate before exiting.
